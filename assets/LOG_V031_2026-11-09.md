# LOG de mudanças — Portal Banco Mestre V031 — 09/11/2026

## Base de partida
- V030 no GitHub Pages, rama gh-pages, site concurso.
- Base canônica V015: 1.494 cartões; 22 cartões operacionais de Ijuí mantidos à parte.
- Imagens: 254 IDs; PDFs catalogados: 63; dados F17 e nove respostas históricas mantidos.
- Nenhum registro de SRS recalculado ou substituído.

## Alterações
1. Novo HTML v031.html e CSS v031.css; V030 mantida para retorno.
2. Assuntos: abrem página temática com subassuntos, explicações, macetes, materiais identificáveis e relações registradas; flashcards são opção de prática.
3. Cartões: respostas em destaque e histórico/fontes/evoluções recolhíveis.
4. Cobertura cruzada: F17 e F14/F16 por IDs da base; similares por mesmo assunto explicitamente rotulados como proximidade temática. Ijuí não é o eixo padrão da cobertura.
5. Vínculos genéricos imagem/cartão e PDF/cartão desativados quando há somente grupo/categoria em comum.
6. Referências IMG-xxx e IDs de PDFs no texto levam a leitores em tela cheia; o ID e o título dos itens do catálogo também são clicáveis.
7. Fontes maiores de imagens correspondidas somente por nome deixam de ser automaticamente usadas se não auditadas (verified===true); miniaturas por ID prevalecem.
8. PDFs: nova camada local baseada em pdf.js e V030 editor, seleção de cópia local sem envio, anotações por página, zoom, cores, caneta, marca-texto, borracha, seleção, desfazer/refazer, exportação de página em PNG anotada.
9. Arquivo PDF original e documentos restritos permanecem no Google Drive. Anotações ficam no localStorage do navegador e não integram o PDF.

## Validação / limites
- Sintaxe dos scripts JS e do script embutido: validada.
- Referências HTML e elementos exigidos: auditados; arquivos novos no repositório.
- Testes manuais de interação em navegador publicado não foram executados nesta sessão: verificação visual e testes com PDF real pendentes.
- Dependência de CDN para PDF.js 3.11.174; se indisponível, ferramenta local informa erro.
- PDF restrito via iframe do Drive não admite desenhos diretos por isolamento entre origens: abrir arquivo local é exigência técnica atual.
- Persistência de marcações somente no navegador; limpar dados do site pode apagá-las.
- Vínculos com imagens/PDFs não confirmados por ID permanecem não associados; correção editorial requer auditoria de proveniência.
