Base b64ab2c7728dbb845be63d0c9ec72110487c3be7. O index.html oficial e o snapshot ficam idênticos. O host isolado deriva a página de teste de seu HTML por uma transformação versionada que modifica exclusivamente o carregador de cartões, desabilita a rota legada e injeta o adaptador.
